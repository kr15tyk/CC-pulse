CC Pulse · Team Brief

Common Criteria ecosystem monitoring, without the manual tab-checking.

CC Pulse automates daily monitoring across NIAP, CSfC, CC Portal, CCTL labs, the CC Crypto Catalog, NIST CSRC, NATO NIAPCL, EUCC/ENISA, and the ND-iTC, then pushes only meaningful changes to a dashboard, RSS feed, email, Webex, or Teams-compatible webhook.

Operational rhythm
06:00 UTC
Daily collect → diff → dashboard → commit → alert. Weekly digest goes every Monday at 07:00 UTC.
Core value
Signal over noise
The project replaces repetitive checks across scattered government portals and lab feeds with one opinionated monitoring flow.

What it covers

NIAP + CC
  • NIAP full PCL with 1,600+ certified products, Protection Profiles, Technical Decisions, CCTLs, and News & Events via JSON APIs.
  • CC Portal international news, PPs, and certified products via HTML scraping and RSS.
  • 8 accredited CCTL lab feeds and posts for evaluation-lab intelligence.
CSfC + NIST
  • CSfC / NSA approved products, 8 capability package PDFs, and 7 NSA/CISA/DISA advisory feeds.
  • NIST CSRC pages, 7 key PDFs including FIPS 203/204/205 and SP 800-131A, plus 3 RSS feeds.
  • CC Crypto Catalog docs including CCDB-018 and related portal publications.
International + iTC
  • NATO NIAPCL certified products with Cisco-specific change detection.
  • EUCC / ENISA scheme requirements and issued certificates.
  • ND-iTC NIT RFIs (the iTC's Technical Decisions — distinct from NIAP TDs) and Allowed-With lists for NDcPP and the FW PP-Module.

How the pipeline works

1
Collect
Nine collectors run in parallel; if NIAP looks thin, the run aborts instead of writing bad data.
2
Diff
Today is compared to yesterday using stable IDs or URLs, with text-prefix matching only as a fallback for linkless scraped content.
3
Scan
Keyword logic scans titles and text against WATCH_KEYWORDS, with tier ranking and Cisco-only CMVP filtering to reduce alert fatigue.
4
Render
The diff is rendered into `docs/cc_dashboard.html` and `docs/cc_feed.xml`, then committed to `main`.
5
Notify
Webex, webhook, and email fire in parallel when alerts exist, with direct links and matched keywords.

Notifications and why they matter

Immediate channels

Keyword-matched alerts go to a Webex space, a Teams-compatible JSON webhook, and an HTML alert email with source, kind, detail, URL, and matched keywords.

Noise control

All keyword matching uses the single `WATCH_KEYWORDS` list, with tiered ranking: Cisco/NDcPP/CSfC keywords rank first, while broad standards identifiers (FIPS 140-3, CMVP) rank as standards-tier so boilerplate can't masquerade as Cisco-relevant. CMVP MIP alerts fire for Cisco modules only, and mass re-detections from source format changes are suppressed as baseline resets.

Cisco moment

A new Cisco certification on NIAP PCL, CSfC, NATO NIAPCL, or EUCC triggers its own celebration path — source-aware header, each product linked to its actual certification page, a meme image, Webex delivery, and matching email alongside normal alerts.
